# FANAKDZ PKG + Assassin's Creed DZ

حزمتان للـ PlayStation 4 (fake PKG) — تُثبَّتان بمُثبِّت الحزم مثل GoldHEN.

| الملف | Title ID | المحتوى |
|---|---|---|
| `IV0000-FANK00001_00-FANAKDZPKG000000.pkg` | FANK00001 | **FANAKDZ PKG** — المتجر الكامل |
| `IV0000-FANK00002_00-ASSASSINSCREEDZ0.pkg` | FANK00002 | **Assassin's Creed DZ** — التطبيق المنفصل (ألعاب Assassin's Creed فقط) |

## التثبيت

1. انسخ ملف `.pkg` إلى الجهاز (مثلًا إلى `/data/pkg` عن طريق FTP).
2. افتح مُثبِّت الحزم على الجهاز وثبّت الملف.
3. يمكن تثبيت الحزمتين معًا — كل واحدة تطبيق مستقل في المكتبة ولا تمحو الأخرى.

## ملاحظات

* التنزيلات والحزم الجاهزة توضع في `/data/pkg`.
* ملف المفضلة في المتجر الكامل يُقرأ من `/data/fanakdz_store.txt` (كلمة لكل سطر).

Two PlayStation 4 homebrew packages (fake PKG), install with a package
installer such as GoldHEN. Both may be installed side by side.
Downloads and finished packages land in `/data/pkg`.
